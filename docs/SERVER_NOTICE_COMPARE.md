## Matcher contract and limits

The pure matcher accepts complete LF, CRLF or CRCRLF records. It supports bare public bodies and two official logger wrappers: debug milliseconds plus thread/function fields together, or nondebug seconds with all those debug fields absent. Wrapped rules check fixed level/function/public-body combinations; masked sessions must match the complete legal field, without a short-mask scan overlapping a legal long mask. Dynamic fields are discarded locally. Only closed enums and fixed metadata are returned; no raw text, fragments, variable values or content hashes are exposed.

Public categories distinguish normal progress (`PROGRESS_NOT_DEVICE_ACCEPTANCE`), negotiation warning (`PROTOCOL_WARNING_NOT_USER_REQUEST`), request text (`REQUEST_TEXT_NOT_OS_ATTESTATION`), denial text (`DENIAL_TEXT_NOT_OS_ATTESTATION`) protocol failure (`AUTH_PROTOCOL_FAILURE_NOT_USER_DENIAL`) and algorithm fallback (`ALGORITHM_FALLBACK_NOT_AUTH_ACCEPTANCE`). A result must match exactly one supported rule. Unknown TLV/handshake values, concatenated records, malformed framing, unsupported fields and inconsistent logger wrappers remain UNKNOWN. A match never authorizes further HDC activity or proves permission/UI state, device acceptance or communication readiness.
