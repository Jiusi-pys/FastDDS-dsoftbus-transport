The generator checks four pinned original Native source/header hashes and exact substitution points, then deterministically produces successor overlays for the consumer and direct main. It leaves the preserved source snapshot intact. The recorder is internal to the opaque test handle; its accessor is hidden within the executable. Public NS POD layouts/API tables, selected return codes and original phase assignments are preserved by design and static evidence.

Main and preconnect-gate diagnostics have independent first-wins slots. Each reason/stage pair is installed together by one 64-bit atomic compare/exchange. Later failures cannot overwrite the first pair. Last-entered main/gate stages are separate atomic observations; they are not a globally simultaneous snapshot or proof of an API's error return. The main reasons distinguish lock/reuse checks, gate registration, descriptor, XML load/mode, participant creation and generic status/exception paths; gate reasons distinguish listener checks, emit, wait and generic exceptions.

The snapshot is copied after execute and local drain while the handle exists, before conditional destruction. Publication is reachable only after the existing local-safe cleanup check. Crash, unsafe close, missing or invalid records remain UNKNOWN. A successful cause write does not establish SDK callback quiet or whole-process-tree termination. Diagnostic serialization/sink failures use a fixed fallback and do not replace the selected status/phase logic; this is not a claim that additional I/O has no timing effect.

The record has eight fixed fields: the `S1GOALCAUSE1` format tag and seven numeric availability/enum fields. It is ASCII, LF-only, bounded to 512 bytes, and carries no private names, identities, paths, exception messages or control content. The decoder rejects extra/reordered fields, noncanonical numbers, invalid enums and incompatible reason/stage pairs. `FIXED_PATH_ONLY` does not prove same-run association. `NO_RECORDED_FAILURE` does not mean success. `producer_contract=NS_ABI_STATUS_PHASE_UNCHANGED_BY_DESIGN` describes the implementation contract, not an observed runtime fact; decoder output keeps `success_inferred=false` and `SDK_quiet=UNKNOWN`.
