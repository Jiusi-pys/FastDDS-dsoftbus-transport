# Public test fixtures

These certificates and private keys are public test data, generated by
`scripts/standards/generate_web_test_certs.py`. They are not deployment secrets.
The generator retains no CA private key. `manifest.json` records the bytes used
in acceptance; `.gitattributes` prevents line-ending conversion.

The trusted server fixture covers localhost and 127.0.0.1. Separate fixtures
exercise an untrusted CA, wrong hostname, expired certificate and mismatched
private key. Regeneration creates new random keys and signatures; it is not
expected to reproduce identical bytes. The normal validity window ends in 2035.
